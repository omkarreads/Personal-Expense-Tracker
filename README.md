# Personal Expense Tracker

A modular command-line Python app to log, manage, and analyze personal expenses.

## Project Structure

- `models.py`: Data classes for transactions and expenses using OOP inheritance.
- `analytics.py`: Spending analytics powered by NumPy and itertools.
- `storage.py`: Handles saving and loading records from JSON file.
- `utils.py`: Input parsing, currency formatting, and logging functions.
- `tracker.py`: Core logic for managing expense records.
- `main.py`: CLI menu interface.
- `test_tracker.py`: Unit test suite using native assert checks.
